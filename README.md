## Descripción del módulo

En el módulo de Desarrollo Web en Entorno Servidor (DWES) aprenderemos a desarrollar aplicaciones web dinámicas utilizando tecnologías de programación del lado del servidor.

Trabajaremos con PHP, programación orientada a objetos, bases de datos, el framework Laravel y el desarrollo de servicios web REST.

Este repositorio recogerá las actividades, prácticas y proyectos realizados durante el curso.
